      // Apple Pickup Watcher / Settings

      Settings

      Saved settings apply at the next check. Nothing here leaves your browser except the notifications you set up.

      // What to watch

      One per line, for example MK1E4LL/A. README Step 2 shows how to find them.

      A 5-digit ZIP code or a store ID such as R191, one per line. Each line covers the 12 nearest stores and adds one request per check.

      // How often

      Each wait is randomized around this number. Below 5 minutes, Apple tends to block requests much sooner.

      Advanced

      // Notifications

      The topic you subscribed to in the ntfy app. Leave empty to turn ntfy off. Anyone who knows the topic can read it, so pick something hard to guess.

      Pushover is used only for "in stock" alerts, which ring until you open them. Use alarm30 after uploading alarm30.mp3 to Pushover.

      Optional. Warns you when the browser closes, the computer sleeps or the internet drops.

      // Buy page

      To stop watching while this is on, turn the extension off in chrome://extensions.
